# Rzvation Hilfe

Die Hilfeseiten zu [Rzvation](https://www.rzvation.com), gebaut mit [Mintlify](https://mintlify.com).

## Lokal ansehen

```bash
npm i -g mint
mint dev
```

Die Vorschau läuft unter `http://localhost:3000`.

## Vor dem Veröffentlichen prüfen

```bash
mint validate
mint broken-links --check-anchors
```

## Veröffentlichen

Änderungen auf dem Standard-Branch werden über die Mintlify-GitHub-App automatisch veröffentlicht.

Schreibregeln und Aufbau der Seiten stehen in [`AGENTS.md`](AGENTS.md).
