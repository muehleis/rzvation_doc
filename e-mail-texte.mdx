Bei jeder Buchung erhalten Ihre Gäste E-Mails, zum Beispiel die Bestätigung oder eine Absage. Rzvation bringt für jeden Anlass einen Standardtext mit. Sie können ihn übernehmen oder eigene Texte schreiben.

<Info>
  **Wo finden Sie das?** Auf der Seite eines Events oder Objekts unter **Weitere Optionen → E-Mail-Texte**.
</Info>

<Note>
  Die Texte gelten für **alle Angebote einer Buchungsseite**. Haben Sie mehrere Buchungsseiten, legen Sie die Texte je Seite fest.
</Note>

## Die Anlässe

| Anlass | Wann wird die E-Mail verschickt? |
|---|---|
| **Anfrage eingegangen** | Der Gast hat gebucht, und Sie geben jede Buchung selbst frei. |
| **Reservierung freigegeben** | Sie haben eine wartende Buchung freigegeben. |
| **Buchung sofort bestätigt** | Der Gast hat gebucht, und die Buchung ist ohne Freigabe bestätigt. |
| **Absage** | Sie haben eine wartende Buchung abgelehnt. |
| **Stornierung** | Sie haben eine Buchung storniert. |

## Text anpassen

<Steps>
  <Step title="Anlass wählen">
    Wählen Sie oben den **Anlass**. Ohne Änderung gilt der Standardtext.
  </Step>
  <Step title="Betreff">
    Ändern Sie den **Betreff**. Die Buchungsnummer wird automatisch angehängt.
  </Step>
  <Step title="Text der E-Mail">
    Schreiben Sie den Text. Der Editor bietet Formatierungen und Tabellen. Mit **Ticketlink einfügen** setzen Sie einen Link auf die Tickets der Buchung.
  </Step>
  <Step title="Vorschau">
    **Vorschau** zeigt die E-Mail mit Beispieldaten, auch mit ungespeicherten Änderungen. Es wird keine E-Mail verschickt.
  </Step>
  <Step title="Speichern">
    Klicken Sie auf **Speichern**. Solange etwas nicht gespeichert ist, steht dort **Ungespeicherte Änderungen**.
  </Step>
</Steps>

Mit **Standardtext wiederherstellen** verwerfen Sie Ihren Text für diesen Anlass. Rzvation fragt vorher nach.

## Platzhalter

Platzhalter werden beim Versand durch die Daten der jeweiligen Buchung ersetzt. Wählen Sie unter **Platzhalter einfügen** einen aus. Er wird in das Feld eingefügt, in dem Sie zuletzt waren, also in den Betreff oder den Text.

| Platzhalter | Wird ersetzt durch |
|---|---|
| Organisationsname, Telefon, E-Mail, Website, Adresse der Organisation | Ihre [Anbieterdaten](/anbieterdaten) |
| Name der Buchungsseite | den Namen der Buchungsseite |
| Veranstaltungsname bzw. Objektname | das gebuchte Angebot |
| Name des Empfängers | den Namen des Gasts |
| Buchungsreferenz | die Buchungsnummer |
| Startdatum, Enddatum, Startzeit, Endzeit | den Termin |
| Gesamtpreis | den Betrag der Buchung |
| Absage-/Stornierungsgrund | den Grund, den Sie beim Ablehnen oder Stornieren angegeben haben |
| Ticketlink | die Adresse der Tickets |
| Liste der Ticketpositionen, Liste der Zusatzoptionen | eine Aufstellung der gebuchten Positionen |

<Note>
  Listen lassen sich nur in den Text der E-Mail einfügen, nicht in den Betreff.
</Note>
